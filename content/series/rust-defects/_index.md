The main reason I've started this web blog was to use it as a medium for a lengthy post
with pieces of critique, complaints, and wishes I've amassed over the few years of using Rust.

But now, a year later, I realize that I will never finish this article unless I subdivide it
into smaller pieces. So now this is a series.

I was trying to come up with some pun on the word "Rust" for the title,
but there are surprisingly few saying and idioms with this word,
so the best I can offer is a nod to some of the problems that non-software engineers face.
